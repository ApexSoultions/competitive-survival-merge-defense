# Content root

Designer-editable data lives here. See `Assets/Documentation/ScalableArchitecture.md`.

| Folder | Purpose |
|--------|---------|
| `Config/` | SceneFlow and similar runtime config |
| `Balance/` | GameBalanceConfig (mana, costs, rewards) |
| `Quality/` | Mobile Low/Mid/High profiles |
| `Abilities/` | Global active ability definitions (M2) |
| `Enemies/` | Enemy definitions (M2+) |
| `Waves/` | Wave tables (M2+) |
| `Units/` | Optional home for UnitData migrations |
